# Logtower 0.2.0

Closing the window used to quit Logtower, and no tray icon ever appeared, on any platform. This release fixes both: closing the window now leaves Logtower running in the tray. It is also the first version that can update itself, so this is the last upgrade you install by hand. The quick log window can now file a log under any project and task, not only the default one. The title screen shows which version you are running.

To upgrade from 0.1.0, install 0.2.0 over it. Your projects, tasks and logs are kept. This release does not change the database.

## There was no tray icon, and closing the window quit Logtower (#25)

The 0.1.0 notes say closing the window leaves Logtower in the tray. That was never true. Logtower registered its tray plugin under the name `tray`, and Tauri registers its own core plugin under the same name after the app's plugins. A later plugin replaces an earlier one with the same name, so Logtower's plugin was dropped. Without it, no tray icon was created and nothing caught the window closing, so closing it quit the app.

Now:

- **The tray icon appears**, and closing the window hides Logtower to the tray. Launching Logtower again, or choosing **Show** in the tray menu, brings the window back.
- **Quit really quits**, from either the tray menu or the dashboard's **Quit** button.
- **Clicking the icon follows each platform's convention:**
  - Windows: left-click shows the window, right-click opens the menu.
  - macOS: a click opens the menu.
  - Linux: menu only, because Tauri reports no tray clicks there.
- **On macOS, clicking the Dock icon brings back a hidden window.**
- The tooltip says "Logtower" instead of "My App".

Quick log still closes for real when you log or press Esc.

## Logtower updates itself (#26)

Logtower checks for a new release when it starts, then once a day while it runs. When it finds one, the title screen shows `vX available` with an **Update** button, followed by the download progress.

- **Windows:** the installer closes Logtower and starts the new version.
- **macOS and Linux:** the title screen asks you to **Restart**.
- **If installing fails:** a link opens the release page so you can download the installer.

Every update is signed, and Logtower installs only updates that carry a valid signature. On Windows, it installs the same kind of installer (`.msi` or `-setup.exe`) you installed Logtower from.

0.1.0 has no updater, so you move from 0.1.0 to 0.2.0 by hand. Releases after 0.2.0 reach you through the app. A failed check, for example while offline, does nothing visible and is tried again the next day.

This release also moves Logtower from Tauri 2.8 to 2.12.

## Quick log can file a log under any project and task (#27)

Quick log always filed a log under the default project and task from the settings screen. To log elsewhere, you had to open the main window and change the default first. The quick log window now has a project select and a task select in place of the "Currently logging for" line. They start at the default, and the log goes wherever they point. Picking a project selects its first task. As on the settings screen, only projects that have tasks are listed.

Picking something here doesn't change the default. When the picks differ from the default, a **set as default** link appears. It saves them as the default, which the main window also picks up now.

## The title screen shows the version (#24)

The dashboard shows the running version, for example `v0.2.0`, in its bottom-right corner.

## Known, and not fixed here

- **No update has been installed through the updater yet.** 0.1.0 publishes no update information, so 0.2.0 is the first release any updater can find. The update flow is tested for real by the first release after this one.
- **Esc does not close quick log while one of the new dropdowns has focus.** Esc is still handled by the message box only. Click into it, or press Tab back to it, first.
- **Quick log still opens only when a default project and task are set.** You cannot create a task from it.
- **On GNOME without the AppIndicator extension, there is no tray icon.** Launching Logtower again brings the window back.
- **On Windows, a new tray icon may be hidden behind the `^` overflow.** Windows decides this, not the app.
- **Not checked before release:**
  - clicking the tray icon and its menu by hand;
  - running this version on macOS or Linux (CI builds and checks both);
  - first run on an empty data folder;
  - upgrading over a macOS `.dmg` install.
- **Still true from 0.1.0:**
  - the installers are not code-signed, so macOS and Windows warn on first run (see the 0.1.0 notes);
  - the hotkey does not work on Wayland;
  - `Ctrl+Space` can be taken by the OS without a warning.
